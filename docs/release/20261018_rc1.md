# RP Usados v1.0.0-rc1 — código preparado para staging

Integra el frontend público y hero final aprobados, seguridad y el panel privado
`/gestion` reconstruido. La versión desktop anterior queda preservada en
`gestion-original-desktop`; no forma parte de la ejecución ni de los paquetes.

Incluye herramientas portables Node 24/pnpm 10.34.7, WordPress local desechable,
Playwright local, build público/privado, tests de seguridad/gestión/caché/UI,
empaquetado determinista e instalación de ZIP en WordPress limpio. GitHub Actions
valida Windows/Ubuntu y ofrece regresión completa de navegador por ejecución manual.

La entrega instalable es el par `rp-usados.zip` + `rp-usados-security.zip`.
`release-manifest.json` identifica commit, tamaños y SHA-256; no instalar un ZIP
cuya procedencia no corresponda al tag revisado. Los archivos fuente de render,
fixtures, DB, uploads demo, herramientas y credenciales no forman parte del par.

Guías para continuar sin esta conversación:

- `README.md`: clonar, instalar, trabajar, verificar y empaquetar.
- `PROJECT_HANDOFF.md`: arquitectura y decisiones que deben preservarse.
- `PRODUCTION_DEPLOY.md`: instalación WordPress real y 24 pasos hasta go-live autorizado.
- `PRODUCTION_SECURITY_CHECKLIST.md`: gates automáticos/manuales/hosting/post-deploy.
- `CACHE_POLICY.md`: privacidad, invalidación y adaptación del proveedor.
- `BACKUP_RESTORE.md`: copias, restauración y rollback.
- `STOCK_ONBOARDING.md`: carga y operación del dueño.
- `docs/report/20261018_rc1_qa.md`: evidencia de QA local.

**No es producción definitiva.** No hubo deploy, compra de hosting, cambio DNS
ni creación de cuenta/stock reales. Antes de salir: staging real, HTTPS/DB,
SMTP, caché, backups/restore, pruebas físicas, accesos del dueño y autorización
de publicación. El sitio puede iniciar sin stock si el dueño lo autoriza; nunca
importar la DB DEMO como inventario.
