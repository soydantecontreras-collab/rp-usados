# Icono de WhatsApp

SVG de Simple Icons descargado el 23/09/2026 desde https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/whatsapp.svg.

Se usa el trazado existente sin redibujarlo. Se presenta monocromo mediante CSS con nombre de servicio en texto visible. No se instaló una librería ni se generó una imagen. El repositorio Simple Icons distribuye sus iconos bajo CC0; los derechos de marca de WhatsApp pertenecen a sus titulares.
