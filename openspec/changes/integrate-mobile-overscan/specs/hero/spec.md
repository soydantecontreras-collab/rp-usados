# Requirements

## Stable expanding mobile media
The dynamic wrapper MUST clip a top-anchored stable maximum viewport canvas.
Copy/CTA MUST use stable small viewport, with native reversible scroll.
### Scenario: toolbar collapses
At +16/+72px, image/copy/CTA positions remain unchanged and additional video
is revealed with no additional empty area. Width/orientation recaptures fit.

## Doorway depth, not full-screen fade
Only the free aperture MUST be darkened, based on presented video frames;
door leaves, bars, handles and frame MUST remain outside the matte.
### Scenario: doors open / reverse
Darkness follows actual frame even during delayed seeks and reverses without
painting an aperture mask over the wrong frame. Desktop receives no effect.
### Scenario: terminal source constraint
If source footage loses all context, approved web presentation must be agreed
before truncating/holding source progress; never claim CSS recovers geometry.

## Complete test preview
All approved components MUST be preserved; demo pages clearly labelled.
### Scenario: public preview
Fresh committed-source export contains Home, nine eligible demo cards and
individual galleries; no sold cards/list prices, V1/WebGL or credentials.
